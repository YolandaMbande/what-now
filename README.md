# WHAT NOW?

A South African young-adult life-admin field guide built with HTML, CSS and vanilla JavaScript.

## Features
- Situation-based practical checklists
- Plain-English adulting dictionary
- Interactive sample payslip decoder
- Important-document checklist saved locally in the browser
- Official-source links for SARS, government ID services, SAPS certification and Employment & Labour
- Responsive mobile layout

## Run
Open `index.html` directly, or use Live Server in VS Code.

## Important
This is an independent educational portfolio project, not government, legal, tax or financial advice. Processes and fees can change; the interface deliberately routes users to official sources for current requirements.
